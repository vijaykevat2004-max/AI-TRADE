Previously observed Basic account: zero technical alerts. An alert() call does not create an alert or a cloud worker. Existing companion v2 and two reconstructed scanners are legacy; archive before changing them. Their current source/compile status is not verified for this replacement. New source below is a candidate, NOT installed or compiled in TradingView yet.

Native chart uses TradingView data. It cannot consume a Yahoo evidence record or acquire saved account drawing-tool control. Proposed partition 20/20/10 with two contexts each requires three scripts, not a naive pair of 25 multi-TF scripts. No new partition is enabled. Native companion candidate uses one daily tuple request, confirmed [1] offsets plus lookahead_on. It does not trigger alerts.
